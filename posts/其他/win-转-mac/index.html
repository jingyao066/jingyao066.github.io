系统设置#

鼠标#

mac默认鼠标滚轮的逻辑和win是相反的，修改方式：
设置->鼠标->自然滚动->关闭。

键盘#

mac上都是command键组合，例如：command+c，command+v，是复制黏贴。
如果外接键盘，win键=command键，因为win在ctrl和alt的中间，这会导致一个问题，win+c或win+v等组合按起来没那么丝滑，可以通过设置键盘映射解决。

设置->键盘->键盘快捷键->修饰键，然后把ctrl键改为command键，command改为ctrl键，就是把俩个键对调。

Mac启动台图标大小调整#

打开终端，执行如下命令：

1
2
3
4

defaults write com.apple.dock springboard-columns -int 10
defaults write com.apple.dock springboard-rows -int 6
defaults write com.apple.dock ResetLaunchPad -bool TRUE
killall Dock
  • 第一行：调整每列显示的图标数量，9表示每列显示9个图标，你可以根据自己的喜好设置其他数字。
  • 第二行：调整行数，这里设置为6，你也可以选择8或其他数字，以达到最佳比例。
  • 第三行：重置Launchpad，使其按照新的设置重新排列图标。
  • 第四行：重启Dock，以便更改生效。

IDEA#

选中单词：
win：ctrl+w
mac：alt+上

左右切换标签页：
win：alt+左或右
mac：command+shift+{}

删除整行：
win：ctrl+y
mac：command+删除键或command+x（就是剪切，只不过不需要选中）

行号：
win：ctrl+g
mac: command+L

解决mac无法更新edge的问题#

  1. 确保你已经完全退出了 Microsoft Edge。
  2. 打开“终端”应用程序。
  3. 直接复制并粘贴下面这行命令，然后按回车。
1
2

sudo rm -rfv /Library/LaunchDaemons/com.microsoft.EdgeUpdater.*
sudo "/Applications/Microsoft Edge.app/Contents/Frameworks/Microsoft Edge Framework.framework/Versions/139.0.3405.125/Helpers/EdgeUpdater.app/Contents/MacOS/EdgeUpdater" --install --system --v=2

解决mac 外接键盘，home和end无法使用#

打开终端，执行：

1
2

mkdir -p ~/Library/KeyBindings
nano ~/Library/KeyBindings/DefaultKeyBinding.dict

写入：

1
2
3
4
5
6
7
8

{
   "\UF729"  = "moveToBeginningOfLine:";        // Home改为移动到行首
   "\UF72B"  = "moveToEndOfLine:";             // End改为移动到行尾
   "$\UF729" = "moveToBeginningOfLineAndModifySelection:";  // Shift+Home
   "$\UF72B" = "moveToEndOfLineAndModifySelection:";        // Shift+End
   "^\UF729" = "moveToBeginningOfDocument:";   // Ctrl+Home（可选）
   "^\UF72B" = "moveToEndOfDocument:";         // Ctrl+End（可选）
}

保存退出（Ctrl+O 回车，Ctrl+X）。
