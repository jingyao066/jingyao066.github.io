安装#

推荐使用sdkman 管理gradle。

安装sdkman#

1

curl -s "https://get.sdkman.io" | bash

安装脚本会引导你完成所有步骤。

查看安装的版本：

1

sdk version

安装gradle#

列出所有可用的 Gradle 版本：

1

sdk list gradle

安装你需要的版本：

1

sdk install gradle 8.5

可以选择安装多版本的gradle。

为特定项目切换版本（推荐做法）：

这是 SDKMAN! 最强大的功能之一。你可以在项目根目录下设置一个默认的 Gradle 版本。当你进入这个目录时，SDKMAN! 会自动切换到该版本。

1
2
3
4
5

# 首先，cd 到你的项目目录
cd /path/to/your/project

# 为当前目录设置 Gradle 版本
sdk env init gradle 7.6.4

这个命令会在项目根目录下创建一个 .sdkmanrc 文件，内容如下：

1

gradle=7.6.4

现在，当你进入这个项目目录时，SDKMAN! 会提示你是否切换到 .sdkmanrc 中指定的版本。

为了让这个功能更流畅，你可以在你的 shell 配置文件（如 ~/.zshrc 或 ~/.bash_profile）中开启自动切换功能：

1
2

# 将下面这行添加到你的 ~/.zshrc 或 ~/.bash_profile 文件中
sdk env auto

之后，每次 cd 进入带有 .sdkmanrc 文件的目录时，版本就会自动切换，无需手动确认。

其他常用命令#

  • 查看当前使用的版本： sdk current gradle
  • 卸载某个版本： sdk uninstall gradle 7.6.4
  • 更新 SDKMAN! 自身： sdk selfupdate
